# 云端记忆索引

每次非琐碎任务先读根目录 `AGENTS.md` 与 `memory/PROFILE.md`。当前消息和用户直接更正优先于历史记录。

- 个人背景、申请、简历、套磁、面试、研究匹配，读取 `memory/durable/personal-profile-index.md` 与 `memory/durable/personal-dialogue-profile.md` 全文，尤其末尾有日期的更正。
- 论文讲解与归档，读取 `references/paper-deepread-standard.md`，按 `environment/skill-catalog.json` 找相关研究技能。
- 飞书、视频、设计、编程等任务，只读取对应 SKILL.md；运行前检查 `environment/CAPABILITIES.md` 中的服务与云端限制。
- 用户要求继续本仓库近期工作时，查 `memory/daily/`、`records/` 和 Git 提交；不要假设能读取 Windows 历史会话。
- 对源文件路径的引用仅用于证据追溯。实际文件不在仓库就明确说明，不能从“记忆写过”升级为“本轮已核验”。

结束前做记忆检查。仅必要的短期延续信息可写 `memory/daily/`；详细记录放 `records/`；稳定偏好和画像修改需用户确认，明确要求的更新不必重复确认。保留历史，不删旧事实，只追加日期或标记被新记录替代。
