# 云端能力与本地差异

**默认可继承的行为**

根目录 `AGENTS.md` 提供沟通、工作推进、技术讲解、论文精读、事实边界和记忆规则。`memory/PROFILE.md` 提供简短画像入口，两份原画像保留完整历史。仓库技能从 `.agents/skills` 发现；当初始列表因数量限制省略条目时，用 `environment/skill-catalog.json` 按主题查路径。

**工具能力按实际可用性判断**

| 能力 | 已迁移内容 | 仍需满足的条件 |
|---|---|---|
| 研究、写作、导师调查、实验设计 | 工作流与参考资料 | 当前联网检索能力；新事实须核验 |
| Python 和网页代码 | 技能、脚本、模板 | 项目自己的依赖与测试环境 |
| 飞书 | 全套 lark 技能，可选固定版本 CLI 安装 | 在云端重新登录或使用已连接插件，不复制本地令牌 |
| 论文与文档抽取 | MinerU 优先的偏好及文档工作流 | MinerU 若不可用，使用已安装的备用提取器，说明质量缺口 |
| Word、Excel、PPT、PDF | 原插件技能参考及本地常用模板 | 原插件的受管运行时可能缺失；可用标准库交付时使用标准库并做渲染验证 |
| 图片生成、Canva、Adobe、Google Drive、Sites | 相关技能参考 | 对应插件、工具和账号必须在当前环境可用 |
| HyperFrames 视频 | 技能、模板与辅助脚本 | 按项目安装对应运行时，实际渲染后才算交付；不默认安装整套视频环境 |
| 浏览器与本机桌面操作 | 操作习惯 | 云端不能据此控制原 Windows 电脑，官方云端能力以当前产品为准 |
| GPU、机器人仿真、训练 | 实验计划、运行与审计技能 | 另行提供并授权计算资源；不把云端普通 CPU 环境当 GPU |
| 本地个人材料与历史项目 | 证据文件的路径索引 | 原件未迁移，路径不可访问；需要时由用户提供 |
| 自动化、提醒、历史聊天 | 不迁移账号运行状态 | 平台级任务需单独配置；仓库内容不等于聊天记录 |

`skill-library/plugins` 是原插件技能的资料副本，不保证对应 MCP（工具连接协议，用于调用外部工具）服务器或受管运行时在云端存在。先检查实际工具。缺少工具时，不执行文档中凭空出现的工具名；普通文档任务可用开放格式库继续，依赖真实账号的操作等待连接。

`environment/local-preferences.json` 只记录本地模型偏好和插件名称，不含服务地址、密钥与完整配置。网页中的模型、推理强度、网络权限由网页设置控制，不用仓库文件强行覆盖。

Windows 路径在画像中保留为出处。技能中的 `~/.claude/skills`、`~/.codex/skills`、`~/.agents/skills` 已适配为仓库技能位置；其他历史路径先通过技能目录或来源清单解析，不能假装本机服务已在云端启动。

本仓库是一次导入。网页端的持久变更需要提交到私有仓库，再由本地明确同步；不会自动覆盖 Windows 上的全局指令或个人画像。

部分本地研究技能原本缺少共享参考文件，其位置记录在 `environment/missing-dependencies.json`。保留可读的工作流程，缺失依赖不冒充已运行。导出的 media-use 遥测模块已改为不采集身份、不发送事件的兼容空实现；原本机文件未改动。
